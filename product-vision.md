# Product vision

Most memory products want a relationship than they admit. ChatGPT Memory accumulates a companion-self across chats. Apple’s personal context acts as a butler. Recorders like Rewind keep an archive because it happened. Notion AI behaves like a workspace brain.

Kivi is a voice product. Users talk to capture work not to be known. Semantic memory should make Hey Kivi a **-session clerk**: it fetches a dictation grounds a fact or applies a writing habit only when asked. That relationship permits remembering artifacts of speech the user meant to keep—not a theory of the person.

If the bond is clerk and author several impressive ideas become inappropriate: a graph of everyone mentioned sentiment over time inferred career goals, who I am" merges. Those require Kivi to assume a mind. A clerk is not entitled to one.

Without memory Hey Kivi formats the utterance. With memory Kivi can (1) recall an episode the user cannot keyword-search, (2) ground a fact they should not re-dictate (3) apply a preference Kivi has shown more than once. That is the set that changes the product from "correct this sentence" to "work with me across days.”

Value is not created at extraction. Extraction is cost. Value is created when the user is blocked—walking into a meeting answering a colleague—. Kivi returns something the user already said, correctly with a way to see why.

Three moments matter. Time-bounded recall must filter (time, app) then rank; embeddings alone retrieve a note, not the right one. Facts must survive contradiction: if Q3 moves from $2.4M to $2.6M serve the belief without pretending the old one never existed. Preferences belong at rewrite time, when Hey Kivi is asked to polish for a purpose—not inside dictation, which styles and phonetics already own.

Remember what would still help in two weeks: named facts, recurring style and the episode itself as append- ground truth. Do not remember today’s logistics, mood, speculation or implications the user did not state. Over-memory is a system that will someday speak a guess in the user’s voice.

Kivi must never assume relationships, inner life or completeness. Missing a dog’s name is not proof there is no dog; it is proof Kivi must not invent one. A new value does not erase history—supersede. Tools that returned nothing are not a license to sound sure.

Trust is operational. Memory is inspectable. Answers cite IDs that appeared in the tool trace. Users edit and reject; old facts are superseded, not mutated in the dark. Fluent lies are product-ending for a clerk. Narrowness is the reason to keep talking: Kivi does not try to know you. Kivi tries to know what you asked Kivi to keep.

The product we should ship is smaller than the product we could infer. That is why the system uses three tables, hybrid retrieval, mandatory citations and a hard rule, against invention.
